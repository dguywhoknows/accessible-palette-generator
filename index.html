Ask it to do things

Press Ctrl+K in the app (Cmd+K on a Mac) and describe what you want. The model chooses from Palette Lab's own functions, runs them in order and tells you what changed. Some examples:

A calm palette for a meditation appGenerates the palette and runs the contrast audit.
Make the accent warmer but keep it accessibleAdjusts the accent and re-checks contrast.
Export it as TailwindShows the Tailwind config ready to copy.

Instructions you save in the same box, such as "keep it short" or "I'm a beginner", are added to every AI request the app makes.

Features

AI palette design
For 7 semantic roles, with names and rationale.
Lock + regenerate
The AI harmonizes new colors around the ones you keep.
OKLCH conversion
Chroma-curved tonal scales (50-950) with binary-search gamut mapping.
WCAG contrast matrix
With AA/AAA/large badges; one-click auto-fix via lightness search.
Color-vision simulation
Protan, deutan, tritan, achromat) with ΔE-OK confusion warnings.
Live product preview
In light and auto-derived dark mode.
Exports
CSS custom properties (+ dark media query), Tailwind config, W3C design tokens.
APCA
WCAG 3 draft) lightness contrast shown next to the WCAG 2 ratio for every pairing, with usage guidance.
Contrast page
Check any text/background pair with live samples at several sizes and get the closest passing text color for AA and AAA.
From image page
K-means clustering in OKLab on a downsampled image, with dominant colors mapped to UI roles and auto-fixed for contrast; the image stays in the browser.

Runs in your browser

All color math, contrast, scales, simulation, dark-mode derivation, exports. None of this needs a network connection or a model.

Uses a language model for

Brief → semantic palette, constrained for accessibility and harmony with locked colors.
